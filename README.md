Explanation about case study, features implemented, and setup instructions

-Case study-
So when i was told to search for a case study, i couldn't think of anything until i saw the AFL 1 tracks in e-learn there i found the utility tools track which i suppose help user in daily activities and more. This was a big mistake from my end because i thought you are not suppose to follow the example idea and instead find your own theme to make an app on. well-oh-well sunday night i read the second section of the AFL 1 details then found out that you have to follow the main theme provided (entertainment, hobby, pop-culture). That's how i come up with my current app where user could input their borrowed item inside the app as a reminder for them to return the item if just in case they forgot. Well.. it fills the "Utility tools" category but the main themes? not so much. but oh well instead of turning the app 180 degrees with so little time, i decided to just submit the app as it is now.
