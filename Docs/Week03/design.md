Design Rationale & Color Scheme (H1)

The seed color i selected for the app is blue (Colors.blue). The main reason is because user is using the app to maintain trust between them and the person they borrowed/lended an item. So i did some research on color theory and found that the color blue represents/resembles trust, According to BINUS University on color symbolism and meanings (https://international.binus.ac.id/graphic-design/2022/06/01/color-meanings-and-the-art-of-using-color-symbolism/). Blue is also used by big tech companies in their logo like intel and microsoft or banks like BCA probably for the same reason. I also used blue because it's highly visible in both dark and light theme, so the user could still easily see the summary_card and other details in both themes.
